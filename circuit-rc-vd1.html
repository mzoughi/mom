A voltmeter (a large, unknown resistance Rv -- not displayed) is always connected directly across the capacitor.
SW CLOSED (charge): Battery drives current through R1 to node A, which is the same node as the capacitor and the voltmeter (no resistor between them). If R is included, it also bleeds current to ground, in parallel with the voltmeter. Steady-state VC = E·Rgnd/(R1+Rgnd), where Rgnd = R ‖ Rv. τcharge = (R1 ‖ Rgnd)·C.
SW OPEN (discharge): Battery disconnected. The capacitor discharges through the voltmeter (and R, if included) back to ground. τdischarge = Rgnd·C.
To find Rv: set R = 0 and discharge -- now τ = Rv·C, so Rv = τ / C. Then set a known R and discharge again; τ = (R‖Rv)·C gives a second, independent way to check your value of Rv.
