SW CLOSED (charge): the battery drives current through R1 to node A, where it splits between R2 → C and R3 → ground. The capacitor charges toward V∞ = E·R3/(R1+R3), a voltage divider, so V∞ < E.
SW OPEN (discharge): the battery is disconnected and C discharges through R2 → A → R3 → ground.
Set R1 or R2 to 0 to short it; set R3 to 0 to remove the R3 branch (then C charges to the full E and, with the switch open, its charge only leaks away slowly through the dielectric). Every reading carries random noise, like a real voltage sensor. Each time you flip the switch a new segment of data begins; pick one under Data to plot it against t − t0. The linearized plots have slope −1/τ. Late in a segment the signal is comparable to the noise, so use the fit window to choose which points to fit.
