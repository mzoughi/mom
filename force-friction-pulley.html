Horizontal Track -- Pulley & Hanging Mass Friction Lab

A block sits on a horizontal track. A string runs from the block over a pulley at the edge of the track down to a hanging mass. In the release test the system is released with a fixed hanging mass. In the add-mass test small masses are added to the hanger until the block slips.

Physics (horizontal track + pulley):
N = m₁g
f_k = μkN  (opposes block's motion)
a = g(m₂ − μkm₁) / (m₁+m₂), if m₂ > μsm₁
Stays put if m₂ ≤ μsm₁
Add-mass test: slips once m₂ > μsm₁, so μs ≈ m₂,c / m₁ (to within one Δm)

f_k does NOT depend on contact area!
μk, μs are redrawn with realistic run-to-run variability (~±15-20%) on every attempt -- just like a real experiment. The same setup may slide one time and not the next!
